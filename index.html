操作说明

从开通到连上

  1. 在套餐对比中选定方案并完成订阅，进入账户复制订阅链接。
  2. 打开客户端下载区，安装当前系统可用的加速器。
  3. 在客户端中选择「订阅 / 配置 URL」一类入口，粘贴链接并更新节点列表。
  4. 按访问目标选择规则模式（全局或分流），再启用连接。
  5. 若页面打不开，先确认订阅仍有效、客户端为较新版本，再尝试更换协议或节点。

使用时的注意点

分流规则能让国内站点走本地网络，减少无谓绕行。游戏或会议对延迟更敏感，需要时再单独切换。流量统计以服务端与客户端显示为准，接近额度时应主动调整使用强度。

常见问题

龙猫云是什么？和 VPN、梯子有何关系？

龙猫云是机场订阅品牌，提供可导入各类加速器的订阅服务。VPN、梯子、网络加速说的是同一类加密代理用途：让设备经订阅链路访问被干扰或延迟较高的站点。本站是查阅套餐与客户端下载的官网入口。

没有技术基础，怎样开始？

按「选套餐 → 复制订阅 → 下载客户端 → 导入链接 → 开启连接」五步即可。第一次建议先在一台设备上跑通，确认浏览器能打开目标站点后，再同步到手机或其他电脑。

客户端必须用官网提供的吗？

建议优先使用本页客户端下载区给出的入口，以便版本与订阅格式匹配。若你已有惯用的加速器，只要它支持通用订阅，也可以自行导入，但更新与兼容性需自行负责。

如何判断该选哪一档？

先估计同时在线设备数和每月流量习惯。轻度浏览通常从入门档试起；设备更多、需要更完整能力时再上调。具体额度与权益以套餐对比模块为准，不要只凭口头转述下单。

导入订阅后仍然连不上怎么办？

依次检查：订阅是否过期、本地网络是否拦截代理端口、系统时间是否准确、客户端是否过旧。可更换协议或节点后再试。若多台设备同时失败，优先从账户侧确认订阅状态。

可以用于哪些系统？

常见桌面与移动系统只要有对应加速器，即可导入同一订阅。请在客户端下载区按系统选择，并留意套餐对同时在线台数的限制。

流量或设备超限会怎样？

超限后可能无法建立新连接或速度被策略限制，以账户内提示为准。可等待结算周期重置，或在套餐对比中改选更匹配的方案。不要把同一订阅无限制地铺到公共环境。
